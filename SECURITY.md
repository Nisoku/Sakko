# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by opening a security advisory at:

https://github.com/Nisoku/Sakko/security/advisories

Please do **not** report security vulnerabilities through public GitHub issues.

## Response

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.

## Disclosure

We follow a 90-day disclosure window after a fix is released.
